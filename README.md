# OSYRN's Female Flight

Female flight with Mage hover, airborne combat, flying stealth and Smooth Staff handling. **Made with controllers in mind. Keyboard supported.**

## Downloads

- [Install the mod on Nexus](https://www.nexusmods.com/skyrimspecialedition/mods/196155)
- [0.2.3 changes, complete source and debug symbols](https://github.com/OSYRN/OSYRN-Female-Flight/releases/tag/v0.2.3)

0.2.3 fixes an AMR loading/holstering crash, airborne crouch walking and dodge interference. It adds compatibility controls and improves animation handling, settings saves and performance overhead.

**Please report bugs or incompatibilities** on Nexus or in [Issues](https://github.com/OSYRN/OSYRN-Female-Flight/issues). Include your Skyrim/mod versions, relevant mods, what happened and logs when available.
